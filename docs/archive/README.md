# Document Archive

제품 확정 전 기획안, 팀별 개발 기록과 참고 자료를 보존하는 공간입니다. 현재 제출
기준 문서는 상위 [`docs/README.md`](../README.md)에서 확인합니다.

| 구분                                  | 내용                                |
| ------------------------------------- | ----------------------------------- |
| `PRODUCT_BRIEF.md` · `indie_cinema_*` | 초기 제품 정의, 요구사항과 실행계획 |
| `onboarding/`                         | 팀 온보딩과 초기 Devnet 자료        |
| `ponyo_work/` · `youn_work/`          | 파트별 작업 기록과 인수인계         |
| `team/`                               | 협업 규칙과 해커톤 체크리스트       |
| `notice/`                             | 주최 측 공지와 기술 세션 원본       |
| `DESIGN.md` · `SCHEMA_CONTRACT.md`    | 디자인 및 데이터 계약 참고 기록     |

아카이브 문서는 당시 의사결정 과정을 확인하는 용도이며 현재 제품 상태를 나타내지
않습니다.
