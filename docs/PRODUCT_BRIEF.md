## 한 줄 설명

AI 에이전트가 계정이나 API 키 없이 Solana USDC로 요청당 비용을 지불하고 유료 API를
계속 실행하는 x402 결제 레이어입니다.

## 문제

에이전트가 유료 데이터나 도구를 만나면 사람은 가입, 결제 수단 등록, 크레딧 충전,
API 키 발급을 대신 수행해야 합니다. 이 과정은 자율 에이전트의 실행을 끊고, 소액
요청에도 구독이나 선불 크레딧을 강요합니다.

## 해결

1. 에이전트가 일반 HTTP 요청을 보냅니다.
2. 서버가 가격이 포함된 HTTP 402를 반환합니다.
3. 에이전트가 예산 정책을 확인하고 Solana Devnet USDC 결제를 서명합니다.
4. 퍼실리테이터가 결제를 검증/정산하고 API가 결과를 반환합니다.

## MVP 성공 기준

- 결제 전에는 유료 응답을 받을 수 없다.
- 에이전트가 402를 인식하고 사람의 API 키 입력 없이 재시도한다.
- 정산 결과를 Solana Explorer에서 확인할 수 있다.
- Docker로 동일한 데모 환경을 재현할 수 있다.

## 해커톤 이후 확장

- Bazaar/MCP에서 유료 도구 탐색
- 에이전트별 예산, 일일 한도, 승인 정책
- A2A 작업 위임과 비용 정산
- 반복 과금 요구가 확인되면 Solana Subscriptions 연동 검토
