## 촬영 체크리스트

- Devnet 표시를 모든 지갑/Explorer 화면에서 확인
- 개인 키, `.env`, 터미널 히스토리, 알림을 화면에 노출하지 않기
- 서버/에이전트/Explorer를 미리 열고 확대 배율 통일
- 네트워크 실패에 대비해 성공 장면을 별도 녹화
- 내레이션보다 실제 `402 → payment → 200` 증거를 우선
