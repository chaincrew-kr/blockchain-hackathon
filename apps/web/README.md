# web

팀 전체가 함께 만드는 프론트엔드 작업 공간입니다. 제품 화면 요구사항이 확정되면
Next.js 또는 Vite 기반 앱을 이 디렉터리에 생성합니다.

## 디자인 레퍼런스

UI/UX 사례는 [Refero](https://refero.design/)에서 참고합니다. 화면을 그대로
복제하지 않고 다음 요소를 중심으로 레퍼런스를 수집합니다.

- 에이전트 작업 입력 화면
- 결제 금액과 승인·진행·실패 상태
- 결과 대시보드와 트랜잭션 링크
- 로딩, 빈 화면, 오류 상태

개발 전에 화면별 참고 사례 1개씩만 고르고, 색상·로고·이미지 같은 브랜드 자산은
복사하지 않습니다.

최소 데모 화면:

1. 에이전트가 호출할 작업 입력
2. `402 Payment Required`와 가격 표시
3. 결제 승인/실행 상태
4. API 결과와 Solana Explorer 정산 링크
